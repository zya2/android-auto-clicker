# オートクリッカー（Android）

Android用の連打・スワイプ自動化アプリです。アクセシビリティサービスの
ジェスチャ機能を使って、指定した位置への自動タップとスワイプを行います。

## 機能

- **1ポイント連打**: 1つの位置を一定間隔で繰り返しタップ
- **マルチポイント**: 複数の位置を順番にタップ
- **スワイプ**: 位置1から位置2へのスワイプを繰り返し
- 間隔（ミリ秒）、スワイプ時間、繰り返し回数（0 = 無制限）を設定可能
- フローティング操作パネルと、ドラッグで動かせる緑のマーカーで位置を指定
- 位置と設定は端末に保存され、次回起動時に復元されます

## 動作環境

- Android 8.0（API 26）以上
- ビルド: Android Studio（Gradle 8.7 / AGP 8.5.2 / Kotlin 1.9.24）

## ビルドとインストール

1. Android Studio でこのフォルダを開く
   （初回は Gradle ラッパーが自動生成されます）
2. 実機を USB デバッグで接続するか、エミュレータを用意する
3. Run ボタンでビルド＆インストール

コマンドラインで APK を作る場合（Android SDK が必要です）:

```
./gradlew assembleDebug
# 出力: app/build/outputs/apk/debug/app-debug.apk
```

## 使い方

1. アプリを開き、「1. アクセシビリティ設定を開く」から
   「オートクリッカー」を有効にする
2. 「2. オーバーレイ許可を開く」から「他のアプリの上に重ねて表示」を許可する
3. モード・間隔・スワイプ時間・繰り返し回数を設定して「設定を保存」
4. 「3. 操作パネルを表示」を押すと、フローティングパネルと緑の丸マーカーが出る
5. マーカーをタップしたい位置へドラッグし、対象のアプリに切り替える
6. パネルの「実行」で開始、「停止」で終了

モードとマーカーの対応:

- 1ポイント連打: マーカー1の位置を連打
- マルチポイント: マーカー1 → 2 → 3 … の順にタップして繰り返し
- スワイプ: マーカー1（開始）→ マーカー2（終了）のスワイプを繰り返し

## 注意

- アクセシビリティサービスは画面の読み取りには使わず、ジェスチャの
  実行だけに使います（`canPerformGestures` のみ）
- ゲームや各種サービスで使う場合は、それぞれの利用規約に従ってください。
  自動化が禁止されているサービスでは使わないでください

## 構成

- `MainActivity.kt` — 設定画面（許可の状態表示、モードと数値の設定）
- `OverlayService.kt` — フローティングパネルとドラッグ可能なマーカー
- `AutoClickService.kt` — ジェスチャ実行用のアクセシビリティサービス
- `Engine.kt` — ジェスチャ列の生成と繰り返し実行
- `ClickConfig.kt` — 設定とタップ位置の保存
